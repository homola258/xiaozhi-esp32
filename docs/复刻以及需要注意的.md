### 克隆到自己的地址

#### http方式

cd H:\Code\esp32\code

git clone https://github.com/78/xiaozhi-esp32.git
cd xiaozhi-esp32



上面是想要存放的文件夹地址

git后面跟的是你的项目地址，可以是你仓库的也可以是别人仓库的

克隆就是在该地址创建一个新文件夹，用来存放项目，绝不能有同名文件夹，否则失败

默认就是名称就是项目名

该方法有时会失效



可以换这个

git clone --depth 1 https://github.com/homola258/xiaozhi-esp32.git remake

就是加了个--depth，仅克隆最新版本



## ssh版本

git clone git@github.com:homola258/xiaozhi-esp32.git remake

流程与上面一致
